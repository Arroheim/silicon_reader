# Ручная проверка

Что не умеют автотесты: мышь, трекпад, системные диалоги, реальные драг-н-дроп и
печать. Канал управления проверяет команды и состояние, а не жесты; падающий Open
на домашней странице (1.0) и невыбираемый масштаб из списка (1.0.2) жили именно здесь.

Как заполнять:

- **Версия** в шапке прогона, рядом macOS и модель Mac.
- **Статус**: `ok`, `fail`, `skip` или пусто (не проверялось).
- **Заметка**: для `fail` что сделал и что получил; баг заводится отдельным пунктом в
  `TODO.md`.

Запуск сборки рядом с установленной версией, с отдельной библиотекой:

```bash
make app
build/SiliconReader.app/Contents/MacOS/SiliconReader -library /tmp/qa-library.json \
    Tests/ReaderCoreTests/Fixtures/djvu2spec.djvu
```

Светлая тема без смены системной: добавить `-NSRequiresAquaSystemAppearance YES`.
